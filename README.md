# Food Recipes Website 

A full-stack web application designed for food enthusiasts to discover, share, and manage their favorite recipes. This project showcases a complete CRUD (Create, Read, Update, Delete) workflow and a robust user authentication system using **Django**.



---

## Key Features

* **Secure User Authentication:** A complete system for Login, Signup, and Profile Management, including custom profile image uploads.
* **Recipe Management:** Users have full control over their content—adding new recipes, editing existing ones, or deleting them.
* **Favorites & Personalization:** Save your favorite community-added recipes to your personal profile for quick access.
* **Community Explore:** A central hub to browse and search all recipes contributed by the community.
* **Data Persistence:** Powered by the Django ORM and a managed database to ensure all user and recipe data is securely stored.
* **Custom Frontend:** Built with vanilla JavaScript, HTML, and CSS for a clean, lightweight, and responsive user experience.

---

##  Tech Stack

* **Backend:** [Django (Python)](https://www.djangoproject.com/)
* **Frontend:** Vanilla JavaScript, CSS3, HTML5
* **Database:** SQLite (Development)
